# OAPPO task 8.

## Description

Консольное приложение реализующее следующие функции работы с файлом:

1. Создание нового файла
2. Просмотр файла
3. Редактирование файла (добавление, изменение, удаление)
4. Отображение списка каждой команды, отсортированной в порядке возрастания веса игроков
5. Отображение самых молодых игроков
6. Отображение самых рослых игроков
7. Отображение самых лёгких игроков

### Technologies

* Java 21
* Maven

## Download project files

Скачайте файлы проекта через терминал

```
git clone https://github.com/Ivanmc-007/com.ivan.ppois._2609.eight
```

### Run in Intellij IDEA

1. Откройте папку с проектом в Intellij IDEA
2. Найдите файл **pom.xml** и кликните по нему правой клавишей мыши. В открывшемся меню выберите пункт **Add as Maven
   Project**

### Deployment on Windows

Windows в русскоязычной локали по умолчанию использует кодировку Windows-1251 (Cp1251) или Cp1252, в то время как
исходные файлы используют UTF-8. Из-за этого возникают крокозябры вместо текста. Ниже приведен способ развёртывания
приложения в Windows 11, устраняющий эту проблему.

1. Скачайте файлы приложения через терминал c github.com
2. Установите Java 21+ и установите системную переменную JAVA_HOME (если не установлены)
3. Скачайте Maven 3.9.0+, распакуйте его и добавьте путь к папке bin в системную переменную Path. (если не установлен)
4. Соберите JAR-архив (eight-1.0.0.jar). Находясь в корневой папке приложения, откройте терминал и выполните следующую
   команду:

```
mvn clean package 
```

5. JAR-архив, который появился в папке target, переместите в удобную для вас директорию.
6. В этой папке создайте текстовый документ следующего содержания (с пустой строкой в конце):

```
@echo off
:: Заставляем само окно консоли работать в UTF-8
chcp 65001 > nul

:: Запускаем Java и принудительно переводим консольный вывод в UTF-8
java -Dfile.encoding=UTF-8 -Dconsole.encoding=UTF-8 -jar eight-1.0.0.jar
pause

```

7. Измените расширение файла на .bat и запустите bat-файл.
